What I built

The migration ran inside a wider warehouse program; my slice was the engineering: I built all 21 ETL jobs and configured all 21 AWS Glue crawlers on daily schedules, and switched the loads from full refreshes to incremental daily loading.

During the migration, an undocumented external-table incompatibility surfaced. It was resolved with a materialize-first pattern — which was then applied across all 21 jobs, so the fix became the standard rather than a one-off.
